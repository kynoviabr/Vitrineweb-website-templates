## 🎨 Personalização rápida

Edite as variáveis no topo de `style.css`:

```css
:root {
  --color-primary: #1a1a2e;   /* Cor principal */
  --color-accent: #e63946;    /* Cor de destaque */
  --font-heading: '...';      /* Fonte dos títulos */
}
```
